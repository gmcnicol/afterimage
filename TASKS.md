# Task Status

Linear is the active source for milestones, backlog ordering, ownership, and
task state.

This file is not a backlog and should not be used to select implementation
work. It remains only as a local pointer so fresh contexts do not treat the old
Studio architecture roadmap as current planning data.

GitHub pull requests are used for implementation review after work is selected
and scoped through the active tracker.

Historical task notes that used to live here may still be recoverable through
git history, but new task state belongs in Linear.
