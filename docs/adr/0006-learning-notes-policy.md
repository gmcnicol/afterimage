# ADR 0006: Learning Notes Policy

## Status
Accepted

## Context
The project is likely to produce important lessons around FFmpeg, cross-platform behaviour, live runtime stability, and headless deployment.

## Decision
Important lessons must be captured as short PEP-style markdown notes in `docs/peps/`.

## Consequences
- decisions and pitfalls remain visible
- repeated mistakes should reduce over time
- future work should inherit working patterns more reliably
