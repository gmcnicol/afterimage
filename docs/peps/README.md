# PEP Notes

This directory stores short project learning notes.

These are intentionally brief and practical.

Use them to capture:

- learnings
- pitfalls
- successful patterns
- wrong assumptions
- cross-platform surprises
- performance or stability findings

## Format
Use the template in `docs/implementation/templates/pep-note-template.md`.

## Naming
`PEP-0NNN-short-kebab-title.md`

## Rule
Prefer a short useful note now over a perfect long note later.
