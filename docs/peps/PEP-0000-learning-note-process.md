# PEP-0000: Learning Note Process

## Status
Active

## Summary
Short PEP-style notes are required to preserve lessons during implementation.

## Context
The project spans multiple runtimes, FFmpeg command generation, cross-platform packaging, and low-latency/live constraints.

## Problem
Valuable lessons are easy to lose between phases, which causes repeated mistakes and wasted time.

## Decision
Capture important lessons in short markdown notes under `docs/peps/` as they are discovered.

## Pitfall to Avoid
Do not wait until the end of a phase to remember what went wrong.

## Success to Continue
Write concise notes next to the work that exposed the lesson.

## Action
When a lesson would save future time, create a new PEP note immediately.
