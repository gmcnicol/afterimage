# Archive

This directory keeps historical planning and specification documents that are
useful for context but are not active implementation guidance.

Use current docs first:

- `../../README.md`
- `../../FOUNDATIONS.md`
- `../architecture/README.md`
- `../product/README.md`
- `../implementation/README.md`

Archived phase/spec files may describe old sequencing, incomplete product
assumptions, or scaffolding-era commands. Treat them as records of project
history unless an active architecture document explicitly points back to them.
