# Archive Metadata Schema

## Purpose

The archive metadata schema connects Darklife archive intelligence with
Afterimage world performance.

It gives Afterimage a stable way to consume motifs, atmospheres, textures,
motion, provenance, recurrence, and behavioural seeds without absorbing the
Darklife pipeline.

## Core Rule

The archive behaves like a memory reservoir, not a generic file manager.

Metadata should answer what this fragment feels like, what motifs recur, what
atmospheres it carries, what behaviours it can seed, where it came from, and
how it relates to other fragments.

## Schema Artifact

The JSON schema lives at:

```text
schemas/archive.schema.json
```

The TypeScript contract lives in:

```text
packages/project-model/src/index.ts
```

Validation lives in:

```text
packages/schema-validators/src/index.ts
```

## Top-Level File

An archive metadata file describes one source asset or archive source.

It includes ID, version, source system, source asset ID, generated time,
provenance, segments, motifs, atmospheres, materials, motion, behaviour seeds,
and recurrence.

The file can be generated by Darklife, Afterimage, or manual curation.

## Segments

Segments identify time ranges within a source.

They include ID, start time, end time, optional label, confidence, tags, linked
motif IDs, linked atmosphere IDs, linked material IDs, linked motion IDs, and
linked behaviour seed IDs.

Segments are the bridge between media time and world memory.

## Motif Candidates

Motifs represent recurring symbolic or perceptual patterns.

Examples include industrial, hallway, surveillance, collapse, and liminal.

Motif candidates include label, confidence, weight, segment references,
descriptor tags, and optional recurrence group.

Motifs may be machine-generated, human-curated, or both.

## Atmosphere Tags

Atmospheres describe emotional and environmental qualities.

Examples include thermal drift, fog, analog warmth, dread, and empty interior.

Atmosphere tags include label, confidence, intensity, segment references, and
descriptors.

Afterimage can map atmosphere tags to scene climates.

## Material Tags

Materials describe visual substance.

Examples include glass, concrete, smoke, tape noise, and corroded metal.

Material tags help aesthetic packs and behavioural systems select plausible
responses.

## Motion Tags

Motion tags describe movement character.

Examples include still, drift, pulse, shake, flow, and collapse.

Motion tags may influence transition choices, field strength, and scene
pressure.

## Behaviour Seeds

Behaviour seeds translate archive intelligence into possible world behaviour.

They include seed type, strength, confidence, segment references, motif
references, atmosphere references, deterministic seed, and optional parameters.

Examples include haze emergence, memory resurfacing, pressure collapse, thermal
bloom, and erosion drift.

## Recurrence

Recurrence links connect motifs or fragments across a source, project, or
larger archive.

They include source reference, target reference, relationship type, strength,
and explanation.

Recurrence is how mythology persists across performances.

## Provenance

Provenance records original source URL or path, rights status, license,
generator identity, generator version, generated time, and notes.

Afterimage must keep provenance visible anywhere archive metadata affects a
composition or export.

## Deterministic References

Projects should reference archive metadata by stable IDs.

Do not reference array positions. Do not depend on local file order. Do not
allow generated archive metadata to silently change render meaning without a
changed sidecar identity or version.
