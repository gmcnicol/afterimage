# Afterimage Architecture

This directory contains the current architectural doctrine, subsystem design,
runtime models, and behavioural system documentation for Afterimage.

The architecture should remain aligned with the principles defined in
`FOUNDATIONS.md`.

- `live-appliance-mode.md`: Live Appliance runtime responsibilities.
