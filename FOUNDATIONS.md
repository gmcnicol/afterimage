# Afterimage Foundations

## TL;DR

Afterimage is an open-source behavioural audiovisual composition and performance instrument.

It is for creating evolving audiovisual worlds from:

- music
- scenes
- visual fragments
- materials
- behaviours
- modulation
- performance gestures
- emotional pressure

Afterimage is not a traditional video editor.

It is not primarily about placing clips on timelines and controlling every frame.

It is about defining worlds, introducing energy into them, shaping their behaviour, performing their evolution, and capturing the resulting traversal.

The renderer is downstream from behaviour.

The canvas expresses intent.

The runtime performs it.

The captured render is the artifact.

---

# Core Metaphor

Afterimage behaves like thick black ink diffusing through water.

A world begins with intent.

From there, the system evolves.

The performer shapes conditions rather than manually animating every frame.

The goal is guided emergence.

---

# Project Maxim

> “A Russian doesn’t take a dump, son, without a plan.”

This project must be built deliberately.

No vibe-driven architecture.

No feature thrash.

No architectural entropy.

The system should evolve carefully toward a behavioural audiovisual instrument.

## Process Maxim

Do not recreate the old CVS habit of treating history as the design.

Use the repository like Git: keep the foundations solid, branch from the current
truth, reconcile deliberately, and let better structure replace earlier
scaffolding. When an old workflow, screen, or implementation pattern conflicts
with the foundations, do the opposite of preserving it by inertia. Migrate it
into the current architecture or leave it behind.

## UI Maxim

The UI must be an inspiration.

Studio should make the foundations feel inevitable: alive, legible, playable,
and emotionally coherent. It should not merely expose data or recreate old
screens with better styling. Each surface should help the user believe in the
world they are shaping and understand what the system is asking them to do
next.

# What Afterimage Is

Afterimage is:

- a behavioural audiovisual composition system
- a visual performance instrument
- a world-state driven runtime
- a scene-based visual ecology
- a modulation-driven rendering environment
- a system for guided emergence
- a deterministic capture/export system

The system should feel:

- alive
- atmospheric
- emotionally coherent
- unstable but steerable
- historical
- performative

---

# What Afterimage Is Not

Afterimage is not:

- a traditional non-linear editor
- a Premiere clone
- a Resolve clone
- a shader toy
- an AI slop generator
- a generic motion graphics suite

The project prioritises:

- atmosphere over spectacle
- behaviour over features
- performance over editing
- emergence over deterministic construction

---

# Core Architectural Principles

## The Renderer Is Downstream From Behaviour

Rendering observes world state.

Behaviour defines the world.

---

## Worlds Are Stateful

Worlds accumulate:

- memory
- pressure
- instability
- recovery
- delayed consequence

---

## Scenes Are Behavioural Climates

Scenes define emotional and behavioural conditions rather than merely organising clips.

---

## Modulation Is First-Class

Modulation affects:

- world state
- behaviours
- fields
- materials
- transitions

---

## Performance Steers Worlds Rather Than Pixels

The performer shapes:

- entropy
- cohesion
- memory
- corrosion
- drift
- collapse

rather than directly manipulating low-level rendering parameters.

---

## Deterministic Export Is Sacred

Realtime emergence may be unstable.

Captured export must remain reproducible.

---

## Future-Proofing Without Premature Architecture

The system should anticipate:

- live performance
- OBS integration
- realtime rendering
- MIDI/OSC/SuperCollider control
- behavioural packs
- plugin extension

without prematurely overengineering the runtime.

Phase one should build seams, not skyscrapers.
